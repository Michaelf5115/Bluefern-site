What the desktop app does

  • Shows every branch in a commit graph

    Open any commit to see which rungs, tags and settings changed.

  • Merges one rung at a time

    When two branches change the same routine, you see both rungs and choose.

  • Keeps safety code whole

    A GuardLogix safety program changed on two branches is never combined: you keep one version.

  • Lists tag and setting changes

    Tags, controller, modules and tasks, each with its old and new value instead of XML.

  • Builds a checked ACD after every pull

    The new ACD is built and compiled in the background, and your old one is backed up.

  • Runs beside an open Studio 5000

    It reads what you last saved and never replaces an ACD that Studio has open.

ACD projects, converted on your PC

  1. You check out a branch

    The app turns the text files in git back into an ACD on your PC.

  2. You work in Studio 5000

    Edit and save as usual. Each save updates the text files.

  3. You commit

    Changes show up rung by rung. Only text goes to the repository.

  • Where it's convertedOn your PC, with the Logix Designer SDK from your Studio 5000
  • What you needStudio 5000 version 31 or later, with SDK access
  • Without SDK accessSave As L5X in Studio 5000 and commit the export
  • What leaves your PCClean text files; the ACD stays where it is
  • Rockwell softwareBluefern never ships or bundles it
  • TwinCAT 3, robots, HMIsAlready text, so no conversion is needed
