Questions

Who counts as an engineer?+

Anyone who commits changes or resolves merges. People who only view projects and history don't need a seat.

Which PLCs and robots do you support?+

At launch: Rockwell Studio 5000 (ControlLogix and CompactLogix), Beckhoff TwinCAT 3, and any robot or HMI program saved as text. Siemens TIA Portal, Omron Sysmac Studio and native robot projects are coming later.

Do I still need Studio 5000 or TwinCAT?+

Yes, to edit your projects. Bluefern doesn't replace your PLC software: your engineers keep editing in it as usual, and reviewing changes works in the browser.

Where is my code stored?+

In a standard git repository on our hosted servers. You can clone it at any time with any git client, so your history is never locked in.

Can I try it on a real project first?+

Yes. Early-access teams get help importing an existing project.
