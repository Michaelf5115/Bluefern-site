The problem

Automation is software now. The tools haven't caught up.

Controls teams write as much code as many software teams, but merge it by hand every week, because generic version control treats a PLC project as one opaque file.

  • The project is one binary file

    Generic git tools can't diff or merge an ACD. When two copies come back, the newest one wins and the other engineer's work is copied over by hand.

  • Two engineers, one machine

    During build and FAT, two people change the same project. Someone ends up comparing the two side by side in Studio 5000 and re-entering rungs one at a time.

  • Nobody is sure what's running

    Line3_final_v7_JM.ACD on a shared drive. Changes made on site never make it back. Finding out what changed, who changed it and why takes an afternoon.

How it works

Text in git. Ladder in the browser. Your PLC software as usual.

Your engineers keep the editor they know. Everything around it gets the workflow software teams rely on.

  1. 01

    Git stores clean text

    Each commit stores the project as readable files, one per program, routine, UDT and add-on instruction. Every change is a small diff with a full history.

  2. 02

    You review it as ladder

    Bluefern draws each routine as ladder logic in the browser, rung by rung. Reviewers see contacts, coils and changed rungs, not XML.

  3. 03

    You keep your editor

    Check out a branch and open the project in Studio 5000 or TwinCAT the way you always have. Nobody has to learn a new editor.

The merge engine

A merge engine that understands rungs.

When two branches change the same routine, the 3-pane resolver shows yours, theirs and the result as ladder logic. You decide what goes in, rung by rung.

  • Conflicts by rung, not by XML line

    Edits that don't overlap merge on their own. When they do, you see the rung from both sides and choose.

  • Checked before it lands

    Every merge is checked before it's saved, so a broken project never reaches main.

  • Nothing changed behind your back

    Code nobody touched comes out of a merge exactly as it went in.
