Clones with any git client

Reviews changes in pull requests

Open a pull request, talk the change through and merge it once it has the approvals your team asks for.

Ladder logic in every pull request

Studio 5000 projects are stored as clean L5X, one file per routine. Bluefern draws each changed rung, the old one in red and the new one in green, so nobody needs Studio 5000 to review.

acme/packaging-cell: pull request 1, files changed

Merges that resolve rung by rung

When two branches change the same routine, you see mine, base and theirs as ladder and choose. Rungs that only one side changed merge on their own.

  • Every merge is checked before it's saved.
  • Code nobody touched comes out byte for byte.
  • Safety programs are never combined: you keep one version whole.
