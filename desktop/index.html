What it does

The git workflow, built for ladder logic.

If you've used a graphical git client, this will feel familiar. The difference is what it understands inside the project.

  • Commit graph

    See every branch and merge at a glance, and open any commit to see which rungs changed.

  • Branches, commit, push and pull

    The everyday git workflow in a window, without the command line.

  • Merges rung by rung

    When two branches change the same routine, you see both rungs and choose, instead of re-entering them by hand.

  • Any git host

    Works with Bluefern repositories and with repositories on any existing git host over HTTPS.

ACD projects

Converted on your PC, with your own Studio 5000.

Git stores readable text, not the binary ACD. The desktop app does the conversion locally with Rockwell's Logix Designer SDK.

  1. 01

    You check out a branch

    The app turns the clean text files in git back into an ACD on your PC, ready to open in Studio 5000.

  2. 02

    You work as usual

    Edit and save in Studio 5000. Nothing about your editor or your habits changes.

  3. 03

    You commit

    The app converts your ACD to L5X, splits it into one file per routine, and commits the text. Only text goes to the repository.

  • Where the ACD is converted

    On your own PC, using Rockwell's Logix Designer SDK from your own Studio 5000 install.

  • What you need

    Studio 5000 version 31 or later, with access to the Logix Designer SDK. The licenses are yours.

  • Without SDK access

    Use Save As L5X in Studio 5000 and commit the exported file. Splitting, ladder view and rung-level merging work the same way.

  • What leaves your PC

    Clean text files go to the repository. The ACD never leaves your PC.

  • Rockwell software

    Bluefern never ships or bundles Rockwell software.

  • Beckhoff TwinCAT 3, robots and HMIs

    These are already text, so they need no conversion.
